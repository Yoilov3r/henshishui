# 恨逝水 · 纂事近

两篇戏文以行楷竖排悬在檐下，雨落成渊。同一份引擎做了两种性情：

| 版本 | 页面 | 雨 | 涨水 | 之后 |
| --- | --- | --- | --- | --- |
| 细雨沉沦版 | [index.html](https://yoilov3r.github.io/henshishui/) | 连绵冷雨，水面安静 | 30 秒起积，600 秒灌满 | 整屏沉入水下，字迹一寸寸隐没 |
| 狂风骤雨版 | [storm.html](https://yoilov3r.github.io/henshishui/storm.html) | 风斜雨骤，电闪雷鸣 | 3 秒起涨，10 秒灌满 | 灌满后整屏如书帛般逐渐四分五裂，碎片漂在虚空里 |

页面左下角有版本互跳的入口；狂风骤雨版多一个喇叭按钮，点一下才有雷声（浏览器不允许自动出声）。

两个页面都是**单文件**：字体以 base64 内联，双击即可打开，无需服务器、无需联网。

## 细雨沉沦版

| 时间 | 状态 |
| --- | --- |
| 0 – 30 秒 | 只有雨。水珠砸在页面下沿，四处溅开 |
| 30 秒起 | 底部开始积水，水面有涟漪、水花与倒影 |
| 30 – 600 秒 | 水位持续上涨（`level = u^1.12`，`u = (t-30)/570`） |
| 淹没处 | 字迹按深度渐隐、染上水色，并随水波微微折射错位 |
| 600 秒 | 整屏灌满，只剩水下的微光与沉着的墨迹 |

## 狂风骤雨版

| 时间 | 状态 |
| --- | --- |
| 0 – 3 秒 | 狂风暴雨：雨丝斜扫、灯笼乱晃、雷电不断 |
| 3 – 10 秒 | 水位急速上涨（`level = u^0.95`，`u = (t-3)/7`） |
| 全程 | 平均 0.7–2.8 秒一次闪电，常带连闪；雷声按距离延迟 0.1–2 秒 |
| 10 秒起 | 满屏水下一片死寂，裂纹从一处开始缓缓蔓延 |
| 10 – 62 秒 | 裂缝沿不规则缝隙一寸寸撕开，碎片逐个松脱，各自漂移、旋转、变暗 |
| 62 秒后 | 碎片在暗流里缓缓散开，雷电继续照亮虚空 |

计时只统计页面可见的时间：切走标签页会暂停，不会被“偷偷”淹掉。

## 操作

- 宽屏：两首诗并排竖排，一屏读完
- 窄屏 / 手机：竖排自动折行成多栏，页面可上下滚动，水面始终贴着视口底部上涨
- 左下角：切换版本；狂风骤雨版可开合雷声

调试参数（正常浏览用不到）：

```
index.html?t=300          直接跳到第 300 秒的水位
storm.html?t=6            狂风骤雨版第 6 秒
index.html?still=1        只渲染一帧（截图用）
index.html?level=0.5      指定水位 0–1
storm.html?bolt=1&still=1 强制一次闪电（截图用）
```

## 文件结构

```
index.html              细雨沉沦版：自包含单文件
storm.html              狂风骤雨版：自包含单文件
src/page.html           页面模板（含引导逻辑、版本跳转、无障碍正文）
src/scene.js            场景引擎：排版 / 雨 / 水花 / 水位 / 沉没折射 / 雷电 / 撕裂
src/audio.js            雷声与雨声（Web Audio 现场合成，零音频文件）
src/poems.js            两篇戏文原文
src/fonts/*.woff2       子集化后的字体（仅含用到的 360 个字）
tools/build_site.py     把字体与脚本内联成两个页面
tools/render.js         离线渲染（Node + @napi-rs/canvas），用于出图校验
tools/render_page.js    端到端校验：把构建产物放进 DOM 桩里跑
tools/audio_smoke.js    雷声合成的冒烟测试
```

重新构建：

```bash
python tools/build_site.py     # 需要 src/fonts/*.woff2
```

## 技术要点

- 纯 Canvas 2D，无依赖。文字（含竖排标点、《》的竖排旋转、朱印）与雨、水、雾、雷电、撕裂全部由同一份渲染代码绘制，因此浏览器里的画面与离线渲染校验的结果一致。
- 竖排排版自建：一列一句，列自右向左；窄屏时按行折行。字号由“能否一屏放下”反推（30 → 16px），不随视口宽度连续缩放。
- 雨：三层景深粒子，受风与阵风影响；撞到水面（或页面下沿）时生成水花、水冠与涟漪，涟漪反过来又扰动水面高度场。狂风骤雨版把风、雨长、雨速、浪高、水花整体放大，并叠加会连闪的闪电。
- 水面：三组行波叠成起伏的浪面，另有一层整体升降（涌浪）与水位上涨时的推力，涟漪再叠在其上。浪尖有被风推着漂的碎沫，水线贴着一层随波起伏的湿膜，水下有斜射光柱与悬浮细屑；水涨到视口顶端后浪花线自然收掉，不会在屏幕边缘留一条白边。
- 沉没：文字先整层预渲染，再按水面裁切、以深度渐变做 `destination-in` 淡出、`source-atop` 染色，最后按竖条错位贴回，得到水下的折射抖动。
- 撕裂：先画进一张离屏帧缓冲，再用 Voronoi 半平面切割出大小不一的多边形碎帛，每条边只向外扩成锯齿撕口。裂口从一处起裂，按距离与随机量逐个“到点”松脱，因此是渐渐撕开而不是整屏齐裂；碎片带各自的旧色，断口有内侧阴影、迎光卷边和毛纤维，离屏后还有一层投影——撕开的是整幅画面，雨和闪电一起被撕开。
- 雷鸣：白噪经低通扫频做闷雷、正弦下滑做低频轰、带通爆裂声做近雷，按闪电距离延迟触发，另有持续的雨声与风声床；全部现场合成，页面里没有任何音频文件。
- 性能：光晕、暗角、颗粒等全部预烘成贴图；大到 2560×1440 时自动下调内部渲染倍率，把绘制量压在约 260 万像素以内。撕裂阶段另用一套约 95 万像素的离屏缓冲，逐片只拷包围盒，避免全屏重复拷贝。
