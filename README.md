# 恨逝水 · 纂事近

一个单文件网页：阴雨不歇的夜色里，两篇戏文以行楷竖排悬在檐下；雨点打在页面底部四处飞溅，停留超过 30 秒后地面开始积水，水位按固定节奏慢慢上涨，被淹没的字迹一寸寸隐没、褪色、沉入水中，直到第 10 分钟整屏灌满。

打开 `index.html` 即可，无需服务器、无需联网——字体已内联进文件。

## 效果说明

| 时间 | 状态 |
| --- | --- |
| 0 – 30 秒 | 只有雨。水珠砸在页面下沿，四处溅开 |
| 30 秒起 | 底部开始积水，水面有涟漪、水花与倒影 |
| 30 – 600 秒 | 水位持续上涨（`level = u^1.12`，`u = (t-30)/570`） |
| 淹没处 | 字迹按深度渐隐、染上水色，并随水波微微折射错位 |
| 600 秒 | 整屏灌满，只剩水下的微光、与沉在里面的墨迹 |

计时只统计页面可见的时间：切走标签页会暂停，不会被“偷偷”淹掉。

## 操作

- 宽屏：两首诗并排竖排，一屏读完
- 窄屏 / 手机：竖排自动折行成多栏，页面可上下滚动，水面始终贴着视口底部上涨

调试参数（正常浏览用不到）：

```
index.html?t=300          直接跳到第 300 秒的水位
index.html?still=1        只渲染一帧（截图用）
index.html?level=0.5      指定水位 0–1
```

## 文件结构

```
index.html              构建产物：自包含单文件（字体以 base64 内联）
src/page.html           页面模板（含引导逻辑与无障碍正文）
src/scene.js            场景引擎：排版 / 雨 / 水花 / 水位 / 沉没
src/poems.js            两篇戏文原文
src/fonts/*.woff2       子集化后的字体（仅含用到的 360 个字）
tools/build_site.py     把字体与脚本内联成 index.html
```

重新构建：

```bash
python tools/build_site.py     # 需要 src/fonts/*.woff2
```

## 技术要点

- 纯 Canvas 2D，无依赖。文字（含竖排标点、《》的竖排旋转、朱印）与雨、水、雾、暗角全部由同一份渲染代码绘制，因此浏览器里看到的画面与离线渲染校验的结果一致。
- 竖排排版自建：一列一句，列自右向左；窄屏时按行折行。字号由“能否一屏放下”反推（30 → 16px），不随视口宽度连续缩放。
- 雨：三层景深粒子，受风与阵风影响；撞到水面（或页面下沿）时生成水花、水冠与涟漪，涟漪反过来又扰动水面高度场。
- 沉没：文字先整层预渲染，再按水面裁切、以深度渐变做 `destination-in` 淡出、`source-atop` 染色，最后按竖条错位贴回，得到水下的折射抖动。
- 性能：光晕、暗角、颗粒等全部预烘成贴图；大到 2560×1440 时自动下调内部渲染倍率，把绘制量压在约 260 万像素以内。
